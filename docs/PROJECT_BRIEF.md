# YolPol Project Brief

## Product

YolPol is an export-focused B2B website for presenting glass packaging
products.

The initial catalog focuses on:

- Beverage glass bottles
- Pharmaceutical glass bottles

Future categories may include:

- Olive oil bottles
- Food packaging bottles
- Related glass packaging products

## Business Goal

The first phase must create a credible, fast, multilingual, and
search-engine-friendly product catalog.

The website should help potential buyers:

- Discover YolPol through search engines
- Browse glass bottle categories
- Review product specifications
- View high-quality product images
- Learn about YolPol
- Contact the company
- Request a quotation

Customer acquisition automation will be implemented only after the
public website foundation is complete.

## Target Markets

The initial commercial focus includes:

- Turkey
- Persian-speaking markets
- Arabic-speaking Gulf markets
- International English-speaking buyers

## Languages

The website must support:

- English (`en`)
- Turkish (`tr`)
- Persian (`fa`)
- Arabic (`ar`)

English is the default locale.

All languages must have crawlable locale-prefixed URLs.

## Phase One Pages

The initial version should prepare the architecture for:

- Home
- Products
- Product details
- Beverage bottles
- Pharmaceutical bottles
- About
- Contact
- Request a quote
- Privacy policy

Not every page must be implemented in the first task.

## Design Direction

The visual identity should feel:

- Professional
- Industrial
- Modern
- Reliable
- Export-oriented
- Minimal
- Premium without excessive decoration

The interface must be responsive and accessible.

## Technical Priorities

1. Correct multilingual routing
2. Static rendering where practical
3. SEO-friendly page architecture
4. Clean Architecture
5. Feature-based organization
6. Strong TypeScript types
7. Server Components by default
8. Testability
9. Performance
10. Future CMS compatibility

## Initial Delivery

The first implementation task is only the project foundation:

- Repository inspection
- Documentation structure
- Internationalization infrastructure
- RTL and LTR handling
- Localized placeholder home page
- Basic SEO foundation
- Quality scripts
- Successful lint, typecheck, test, and build

Product domain implementation belongs to the next task.
